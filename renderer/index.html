HCPToolKit - Diagnóstico y Mantenimiento
⚠️ Estas utilidades requieren permisos de administrador. Se abrirá una ventana CMD visible.
SFC /SCANNOW — Comprueba la integridad de los archivos protegidos del sistema y repara los dañados (la consola no se cierra automáticamente).

DISM — Repara la imagen de Windows descargando archivos oficiales desde Windows Update (la consola no se cierra automáticamente).

Diagnóstico de Memoria — Inicia la herramienta mdsched.exe para comprobar si la memoria RAM presenta errores físicos.
